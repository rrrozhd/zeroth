# MCP and Vault Runtime Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve declarative MCP configuration, deny MCP process startup before side effects, and remove synchronous Vault I/O from async service paths.

**Architecture:** MCP requirements are validated at author time and enforced before manager construction. Secret providers gain an async compatibility helper; Vault owns a reusable async client with per-key and token single-flight locks.

**Tech Stack:** asyncio, httpx, MCP Python SDK, Pydantic v2, pytest-asyncio.

**Dependency:** Integrate runner changes after the runtime-isolation plan so MCP managers remain dispatch-local.
